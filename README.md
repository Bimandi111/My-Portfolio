# Bimandi Nesanga — Portfolio

A modern personal portfolio website for showcasing software engineering experience, technical skills, education, and selected projects.

## ✨ Highlights

- Responsive single-page portfolio layout
- Dark, modern visual design with glassmorphism styling
- Animated UI elements and scroll reveal effects
- Navigation, mobile menu, and custom cursor interactions
- Downloadable resume section
- Social and contact links for GitHub and email
- Favicon and branding assets included

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Tailwind CSS CDN
- Lucide icons
- Netlify hosting

## 🚀 Getting Started

### Prerequisites

- A modern browser
- Git installed locally

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Bimandi111/portfolio.git
cd portfolio
```

2. Open the project locally:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## 📄 Resume Download

The portfolio includes a resume download button that links to the PDF stored in:

- [assets/Bimandi_Nesanga_Resume.pdf](assets/Bimandi_Nesanga_Resume.pdf)

## 🎨 Customization

Edit the content directly in [index.html](index.html) and styles in [style.css](style.css) to update:

- Personal name and role
- About/experience information
- Skills and project details
- Contact links
- Brand colors and layout accents

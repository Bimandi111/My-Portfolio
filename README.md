# Bimandi Nesanga — Portfolio

A modern personal portfolio website for showcasing software engineering experience, technical skills, education, and selected projects.

## ✨ Highlights

- Responsive single-page portfolio layout
- Dark, modern visual design with glassmorphism styling
- Animated UI elements and scroll reveal effects
- Navigation, mobile menu, and custom cursor interactions
- Downloadable resume section
- Social and contact links for GitHub and email
- Favicon and branding assets included

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Tailwind CSS CDN
- Lucide icons
- Netlify hosting

## 🚀 Getting Started

### Prerequisites

- A modern browser
- Git installed locally

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Bimandi111/portfolio.git
cd portfolio
```

2. Open the project locally:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## 🎨 Customization

### Edit Personal Information
Edit `index.html` to update:
- Name and title in hero section
- About section content
- Skills and technologies
- Project details and links
- Education and experience

### Modify Colors
Update CSS variables in `style.css`:
```css
--primary: #C77D9D;  /* Primary accent color */
--t1: #F7F3EE;       /* Primary text */
--t2: #B8B4AD;       /* Secondary text */
```

### Add/Remove Sections
- Duplicate section elements in `index.html`
- Update navigation links
- Add corresponding styles in `style.css`
